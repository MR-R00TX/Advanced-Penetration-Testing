## 🧭 Attack Chain Summary

1. **Recon** — `nmap -sV -sC -p-`, `nmap --script vuln`, `nikto` → SSH (22) + Apache (80), directory indexing enabled on `/image/`
2. **Enumeration** — browsed the indexed `/image/` directory → found an exposed `id_rsa` private key, `users.txt`, `Password.txt`, `reverse-shell.php`
3. **Credential Cracking** — `ssh2john` + `john` (fasttrack wordlist) cracked the key's passphrase in ~1 second
4. **Initial Access** — SSH in as `icex64` using the recovered key (legacy `ssh-rsa`/KEX algorithms re-enabled manually)
5. **Privilege Escalation #1** — `sudo -l` allowed running `heist.py` as `arsene`; the imported `webbrowser.py` module was world-writable → hijacked it with a reverse-shell payload to pivot to `arsene`
6. **Privilege Escalation #2** — `arsene` had unrestricted `NOPASSWD` sudo on `pip` → classic [GTFOBins](https://gtfobins.github.io/gtfobins/pip/) `setup.py` trick → **root**
